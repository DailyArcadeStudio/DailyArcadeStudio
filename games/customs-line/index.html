カスタムズ・ライン

審査ブースは一人分の幅しかない。列は止まらない。

あなたの仕事

  • 旅客が一人ずつブースに立つ。通すか止めるかを選ぶ
  • 持ち時間はゲージ一本ぶん。切れたら誤判定と同じ扱い
  • 正しく捌くほどスコアが伸び、列は速くなる

密輸の見分けかた

  • カバンの赤い縫い目が光っている者は黒。止める
  • 光っていなければ白。通す。止めれば誤判定
  • 汗や挙動はただの演技。縫い目だけを見る

操作

  • キーボード: ← 止める / → 通す
  • スマホ: 左スワイプで止める / 右スワイプで通す
  • 迷ったら止める、は通用しない。白を止めても信用は減る

予告なく起きること

  • 停電: 非常灯だけになり、縫い目が見づらくなる
  • 団体客: 列が一気に詰まり、持ち時間が縮む
  • 外交官: 金色の旅券。中身に関係なく通す
  • 抜き打ち監査: 一度でも間違えれば信用が二つ飛ぶ
