カイト・ストリング

凧は二つ。糸も二本。地面に着いたら終わりです。

凧

  • 風でいつも 少しずつ沈みます。放っておけば落ちます
  • 糸を引くと 上がる。離すと 下がる
  • 左右は別の凧。同時には引けません

糸

  • 引いている糸だけが 張ります
  • 張っていない糸は緩み、凧はそのまま落ちていきます
  • だから交互に引く。それがこのゲームの全部です

もつれ

  • 二つの凧が 近づきすぎる と糸がからみます
  • からむと両方 いっぺんに沈む
  • 離せばほどけます。近づけないことが一番の対策です

地面

  • どちらか一方でも 地面に触れたら終わり
  • 高さの計は画面の下、左右に一つずつ
  • 赤くなったら、その色の凧を引いてください
