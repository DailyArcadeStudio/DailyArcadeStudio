灯台の合図

沖の船が光る。同じ順番で灯りを返す。ブラウザだけで遊べます。

船の合図

  • 沖の船が色つきの光をひとつずつ点滅させます
  • 点滅が終わるまで、こちらは何も押せません
  • 合図は毎回一つずつ長くなっていきます

返信

  • 灯台のレンズは4色に分かれています
  • 見た同じ順番で色を押し返します
  • 順番を間違えたら、その場で終わりです

持ち時間

  • 返信中は波の砂時計が減りつづけます
  • ゼロになる前に返しきること
  • 合図が長くなるほど、余裕はなくなります

操作

  • 画面の四隅（上下左右）をタップ、またはその方向へスワイプ
  • キーボードは ← ↑ → ↓ もしくは A W D S
  • 押す色は、レンズに出ている位置と同じです
